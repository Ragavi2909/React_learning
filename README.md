what is react?
 - js library
 - to build ui
 - follows component based development (component is reusable and self-contained[how it behaves])


 diff between react, react js and react native
 - we can write code using either js or typescript, that's the reason for naming as react (library)
 - if we write code in js , we call it as react js (library)
 - but react native (framework) is different , used for building cross platform applications like android, ios and web browsers

 Note:
 - Framework is a template


 Steps to setup environment for react:
 - node -v [to check whether node insatlled and what version]
 - configure the build tool -> vite
        - npm install vite@latest [to install vite]
        - npm create vite@latest , then projectName, package name, select framework (here react), select version (here javascript) and then yes
 - then type these commands:
        - cd React-App (here)
        - npm install
        - npm run dev
